# 🪔 अकेलवा पूर्व दुर्गा पूजा समिति — वेबसाइट

Next.js 14 + Tailwind + Three.js। पूरी वेबसाइट हिंदी में। कोई बाहरी database ज़रूरी नहीं — सारा data `data/db.json` में रहता है।

## चलाने का तरीका
```bash
npm install
cp .env.local.example .env.local     # फिर ADMIN_PASSWORD ज़रूर भरें
npm run dev                          # http://localhost:3000
npm run build && npm start           # production
```

## पेज
| पेज | काम |
|---|---|
| `/` | कॉस्मिक intro, दुर्गा माँ, लाइव कुल जमा, टॉप-5 दानदाता, खर्च, संपर्क |
| `/donors` | पूरी दानदाता सूची (खोज सहित) |
| `/expenses` | खर्च का चार्ट व पूरी सूची |
| `/notice` | सूचना पट्टी + कार्यक्रम सारणी (कब, कहाँ, कितने बजे पहुँचना है) |
| `/gallery` | फ़ोटो गैलरी (श्रेणी फ़िल्टर + बड़ा देखना) |
| `/donate` | UPI QR + दान विवरण फ़ॉर्म |
| `/admin` | पुष्टि, दान (फ़ोटो सहित), सूचना, कार्यक्रम, अतिरिक्त सेक्शन, खर्च, गैलरी, सेटिंग, बैकअप |

## दान कैसे काम करता है
1. भक्त `/donate` पर UPI से भुगतान करता है और फ़ॉर्म भरता है।
2. दान **"पुष्टि बाकी"** में जाता है (सूची/कुल में नहीं जुड़ता) — इससे कोई झूठा दान नहीं डाल सकता।
3. कोषाध्यक्ष बैंक/UPI में पैसा देखकर `/admin` → **पुष्टि** दबाता है → तभी सूची में आता है।

## ज़रूरी बातें
- **Hosting**: Oracle Always Free पर चलाने की पूरी गाइड `DEPLOY-ORACLE.md` में है। data फ़ाइल में सेव होता है, इसलिए ऐसी जगह चलाएँ जहाँ disk स्थायी हो (VPS, Render disk, Railway volume, अपना PC)। **Vercel/Netlify पर यह सेव नहीं होगा।**
- **Backup**: `data/` और `public/uploads/` फ़ोल्डर की कॉपी समय-समय पर रखें (ये git में नहीं जाते)।
- **UPI ID** `/admin` → सेटिंग में असली ID डालें।
- **Zip बनाते समय** `node_modules` और `.next` शामिल न करें (ये 450MB+ होते हैं और `npm install` से दोबारा बन जाते हैं)।

## एडमिन पैनल कैसे खोलें
- पता: `https://आपकी-साइट/admin` (अब मेन्यू में लिंक नहीं है — URL खुद लिखकर खोलें)
- Password: `.env.local` का `ADMIN_PASSWORD`। **अगर सेट नहीं किया तो डिफ़ॉल्ट `akelwa123` चलेगा — तुरंत बदलें।**

## दानदाता दीवार (दान के हिसाब से बड़ी फ़ोटो)
- एडमिन → सेटिंग → "दानदाता स्तर" में हर स्तर की न्यूनतम राशि और फ़ोटो का आकार (px) बदला जा सकता है।
- भक्त `/donate` पर अपनी फ़ोटो जोड़ सकता है; फ़ोटो तभी दिखती है जब एडमिन दान की **पुष्टि** करे। अज्ञात दान में फ़ोटो कभी नहीं दिखती।
- एडमिन किसी भी दान में खुद भी फ़ोटो जोड़/बदल सकता है।
